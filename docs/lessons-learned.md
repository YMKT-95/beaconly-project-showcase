# Lessons Learned

## Design for Change
Repeated hardcoded flows become expensive once categories and business-rule combinations grow.

## Understand the Data Model Early
Entity relationships directly influence APIs, validation and UI behaviour.

## Frontend Developers Benefit from Backend Awareness
Understanding controller, service and data-access layers helped with integration and debugging.

## Reuse Mature Services
Clerk, Material UI, Mapbox and AWS services reduced unnecessary reinvention.

## Use Testing as a Design Input
Structured usability testing helped identify where the workflow was effective and where further
improvements were needed.

## AI-Assisted Development Still Requires Ownership
AI can accelerate implementation, but developers must still understand the system, write precise
requirements, evaluate generated changes and own architectural decisions.
