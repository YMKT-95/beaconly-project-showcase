# Project Overview

## Goal

Beaconly was designed as a digital community-safety platform for better communication between
residents and law-enforcement users.

## Resident Experience
- Submit reports
- Receive AI-assisted category suggestions
- Complete category-specific information
- Track report status
- View public alerts
- Explore alerts on a map

## Police / Staff Experience
- Review incoming reports
- Convert or merge reports into cases
- Maintain case progress
- Generate/edit case summaries
- Publish and update alerts

## AI-Assisted Features
The project explored:
- category classification
- smart autofill
- case summaries
- merge-report suggestions

The intention was to reduce repetitive work while retaining human review and editable outputs.
