# My Contributions

This was a team project. The points below describe areas I personally worked on or helped shape.

## Frontend Architecture
I worked on structuring the frontend into separate UI, routing, context, hooks, API, types and
validation layers.

## Authentication and Profile Flows
I worked on authentication/profile flows and role-aware frontend behaviour around Clerk-based
authentication.

## Configuration-Driven Report Forms
I helped move report forms away from repeated hardcoded category flows toward declarative config
plus shared rendering logic.

## Rule-Based Validation
I worked on separating validation rules from UI components and organising reusable form/entity rules.

## Debugging and Maintainability
I focused on tracing user-facing problems to root causes and making small, maintainable changes
rather than applying surface fixes.

## Frontend / Backend Integration
I needed to understand backend DTOs and controller/service/data-access responsibilities to integrate
frontend features correctly.
